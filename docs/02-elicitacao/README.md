# 02 · Elicitação de Requisitos

Esta pasta centraliza os registros e resultados das técnicas de elicitação utilizadas para levantar as necessidades dos discentes, instrutores, professores curadores e administração da UFC Quixadá.

## Estrutura sugerida

Adicione aqui os documentos produzidos na disciplina, como:

- **Personas e Stakeholders** — Perfis de Participante, Instrutor, Professor Curador e Administrador.
- **Técnicas de Elicitação** — Roteiros e sínteses de entrevistas, questionários, brainstorming, análise de documentos/processos institucionais ou observação.
- **Lista Inicial de Necessidades** — Requisitos brutos coletados antes da priorização e formalização no SRS.
